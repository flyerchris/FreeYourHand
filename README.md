# FreeYourHand (Mac 語音輸入潤稿工具)

FreeYourHand 是一個針對 Mac 用戶開發的高效語音輸入工具。它結合了 Apple Silicon 優化的本地 Whisper 辨識技術與 Gemini API 的校對能力，實現「語音輸入、精確還原、即時貼上」的無縫體驗。

## ✨ 核心特色

- **本地語音辨識**：使用 `mlx-whisper` 在本地端進行快速的語音轉文字（支援中英文），保障隱私。
- **AI 智能潤稿**：透過 Gemini API 修正逐字稿。精確修正同音異義字、補上標點符號，同時**百分之百還原您的真實語氣與風格**。
- **無縫即時貼上**：處理完成後，自動將文字寫入剪貼簿，並在您當前的游標位置貼上 (`Cmd + V`)。
- **翻譯模式**：支援一鍵將語音辨識內容精確翻譯為英文輸出。

## 🚀 系統需求與安裝

本專案推薦使用 [uv](https://docs.astral.sh/uv/) 作為 Python 的套件與環境管理器，它能大幅提升虛擬環境建立與套件安裝的速度。

### 1. 系統前置需求

在開始之前，請確保您已經安裝了 `portaudio` 與 `ffmpeg`（這些是麥克風收音與語音處理的必備依賴）。您可以使用 Homebrew 來安裝：

```bash
brew install portaudio ffmpeg
```

### 2. 安裝 `uv`

如果您尚未在系統中安裝 `uv`，請使用以下任一方式安裝：

**方式一：透過 Homebrew (推薦)**
```bash
brew install uv
```

**方式二：透過官方腳本**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 3. 下載專案與建立環境

將終端機切換到專案目錄，並使用 `uv` 來同步安裝環境與相依套件：

```bash
# 進入專案目錄 (請替換為您實際的專案路徑)
cd /Users/leon/antigravity/FreeYourHand

# 使用 uv 同步並安裝所有 requirements.txt 或 pyproject.toml 裡的相依套件
uv sync
```

## 💡 如何執行

專案設定完成後，使用 `uv run` 即可自動在該環境中執行應用程式：

```bash
uv run main.py
```

初次啟動時，程式會引導您：
1. **授予權限**：開啟 macOS 的介面，請授予「麥克風 (Microphone)」與「輔助使用 (Accessibility，這是為了讓程式能夠自動執行 Cmd+V 貼上操作)」權限。
2. **模型下載**：程式會自動下載本地端所需的 Whisper 語音模型（會在背景出現下載進度條）。

## 📖 工具使用詳細說明

### 系統設定與配置

應用程式啟動後，不會有主視窗，而是會常駐於右上角選單列（Menu Bar）中，顯示一個麥克風圖示。請點擊該圖示並選擇 **「設定 (Settings)」** 來完成初始配置：

1. **Gemini API 設定 (必須)**：
   - 您必須在「Gemini」分頁中輸入您的 **Gemini API Key** 才能啟用 AI 潤稿與翻譯功能。
   - 可以在左側選單選擇偏好的模型（預設為最新速度最快的 `gemini-2.5-flash`）。
2. **快捷鍵自定義**：
   - 預設語音輸入鍵為 **右側 `Option` 鍵 (Right Option)**。
   - 若您想更改，可以在「快捷鍵 (Hotkeys)」分頁中將其設定為符合自身習慣的按鍵組合。
3. **自定義校對指令 (Prompt)**：
   - 若您對預設的潤稿邏輯有特定需求（例如希望系統強制輸出特定專業術語、或是調整語氣修飾的幅度），可以在設定視窗中編輯修改您的系統 Prompt。

### 操作流程

1. **準備輸入**：將滑鼠游標放置在任何可以輸入文字的地方（如 Notion、Line、瀏覽器網址列或是程式碼編輯器中）。
2. **開始錄音（一般精確還原模式）**：
   - **長按** **右側 `Option` 鍵**（或您自訂的觸發按鍵）。
   - 畫面正下方會浮現並顯示一個動態聲紋（Waveform）能量條，這代表正在收音中。此時請直接對著麥克風說話。
3. **開始錄音（翻譯模式）**：
   - 說話時，長按 **右側 `Option` 鍵** 的同時，按住 **`Shift` 鍵**。
   - 系統將會把您的語音內容（不論中文或英文）全部翻譯並優化為流暢的英文後輸出。
4. **處理與輸出**：
   - 說完話後，**放開按鍵**。
   - 畫面下方的聲紋棒會轉變為一個一直旋轉的轉圈動畫，表示系統正在「辨識 -> AI 潤稿」的流程中。
   - 處理完成後，工具會模擬 `Cmd + V` 按鍵。修飾過且毫無錯字的文字，就會在您剛剛游標停留的位置瞬間蹦出！

### 查看除錯日誌
若您發現辨識出來的文字不如預期，或者操作沒有反應，可以點選右上角狀態列圖示，選擇 **「查看日誌 (Logs)」**。
裡面會詳細記載應用程式運行的狀態，包含：
- mlx-whisper 生成的原始逐字稿（Transcript）。
- Gemini API 的連接狀態與最終處理完畢的文字。
- 發生的任何系統錯誤及權限問題。

## 🛠️ 打包為獨立 Mac App (發佈模式)

如果您希望將此工具打包成一個可以直接在 Launchpad 中點擊執行的 `FreeYourHand.app`（不用保留終端機視窗）：

```bash
# 確保打包工具已安裝
uv pip install py2app

# 執行打包腳本
uv run python setup.py py2app
```

編譯完成後，完整的應用程式將會出現在專案底下的 `dist/FreeYourHand.app`。您可以直接將該檔案拖曳移動至您 Mac 的「應用程式 (Applications)」資料夾中直接使用。
